# Edge Drawer

一个贴着屏幕边缘的「抽屉」——把文件拖进去收纳。灵感来自 macOS 的 EdgeShelf，基于 Electron 实现。

## 交互

- **仅拖动触发**：鼠标在屏幕指定边缘 **20px 内**按住并向内拖 ≥ **40px** 才滑出抽屉，不悬停自动弹出。
- **边缘可配置**：抽屉可贴在屏幕**左**或**右**边缘（设置里切换）。
- **多屏支持**：按各显示器 workArea 定位，处理显示器增删与缩放变化。
- **收纳文件**：把文件拖入抽屉，自动复制到收纳目录（默认 `~/EdgeDrawerStore`，可改）。
- 点击文件用系统默认程序打开；悬停可删除。

## 技术

- Electron 主进程：无边框透明置顶窗 + `uiohook-napi` 全局鼠标监听判定「边缘起拖」。
- 渲染进程：抽屉 UI、文件网格、拖拽收纳、设置面板。

## 运行

```bash
npm install
npm start
```

## 结构

```
src/
  main.js      # 主进程：窗口、全局鼠标、多屏定位、文件存储
  preload.js   # IPC 桥
  index.html   # 抽屉 UI
```
